# Design system visual

## Direção

A interface usa uma direção editorial imobiliária: verde profundo para
estrutura e contraste, cobre para ação e destaque, creme/areia para superfícies
e Fraunces + Manrope para contraste entre títulos e texto funcional. A
hierarquia privilegia espaço, fotografia e tipografia; não usa neon,
glassmorphism ou gradientes decorativos como linguagem principal.

## Componentes recorrentes

- `.shell` define a largura de leitura e mantém margens responsivas;
- `.button` e variantes concentram estados de ação;
- `.search-card` e `.contact-form` agrupam tarefas sem multiplicar cards;
- `.listing-card` mantém imagem, localização, título, preço e metadados;
- o painel usa `admin-button`, `outline-button`, tabelas e estados inline.

## Critérios

Foco visível, texto real do negócio, estados de carregamento/erro/sucesso e
contraste são parte do componente. Não adicionar métricas, prêmios,
depoimentos ou dados imobiliários que não venham do banco/configuração.
